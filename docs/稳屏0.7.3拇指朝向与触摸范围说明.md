# XREAL 稳屏 0.7.3

请手动覆盖安装 `XREAL-StableScreen-v0.7.3.apk`，Server 和 Demo 无需更新。

左手持屏顶部默认向大拇指侧转 90°。在“左手持屏 → 顶部朝向”可按 5° 调节：
0° 朝四指，90° 朝拇指侧，途中可选择舒服的握持角度。掌心侧位置和正反面显隐规则保持不变。

直接触屏的判定范围增加两项毫米设置：

- “屏幕后方触摸厚度”：0～200 毫米，步进 1 毫米。
- “触摸保持容差”：0～30 毫米，步进 1 毫米，作用于按住后的前后方向及画面边缘。

点击“精确触屏”可同时归零。0 毫米表示只检测屏幕平面，快速穿过平面也能形成点按；
设为零时不会额外保留原先几厘米的保持范围。每次新触碰仍需先退回屏幕前方约 5 毫米再触入。
需要连续滑动时可增加少量厚度或容差；“连续滑动”预设为厚度 10 毫米、容差 2 毫米。

旧的后方厚度设置会保留，新安装默认厚度和容差均为零。改参数会松开当前触控。
拇指方向和新的触摸范围已通过离线回归，实际手感待安装后确认。
