# XREAL 稳屏 0.7.1

请手动覆盖安装 `XREAL-StableScreen-v0.7.1.apk`，Server 和 Demo 无需更新。

左手持屏改为类似拿手机的放置方式：

- 屏幕平面平行于左手掌面，中心位于掌心一侧约 3 厘米。
- 屏幕顶部沿手腕到四指根部方向，横边与该方向垂直；随左手完整移动、转动。
- 只有掌心朝向眼睛时显示。掌背朝向眼睛、侧到接近边缘或左手丢失时，隐藏屏幕、边框和触控指示，并松开正在进行的触控。
- 手心重新朝向眼睛后恢复显示。重新操作前，捏合模式先张开；直接触屏模式先退回屏幕前方再触入。

安装后开启眼镜画面、投屏和“将屏幕绑定到左手”。不需要首次开启时对准视线来决定屏幕角度。
“1 秒后重新适配左手屏幕大小”只重新适配近手尺寸，屏幕角度始终按掌面决定。
透明手部骨骼仍可独立显示；掌背时隐藏的是手机屏幕，不是骨骼。

本版已加入掌面方向、正反面可见性和连续触控回归检查，实际佩戴效果待安装验证。
