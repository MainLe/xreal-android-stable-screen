# 静态手机截图与立方体对照

安装 `XREAL-ScreenshotCompare-v1.0.5.apk`，覆盖原空间 Demo（包名 `dev.xreal.server.features`）。稳屏和 Server 无需更新，保存的锚点地图保留。先退出稳屏，再从 Server 启动空间 Demo；不要同时运行两份眼镜渲染应用。

进入“追踪”页，点 **1 秒后把截图和立方体放到面前**，看向希望摆放的位置。等真实 6DoF 位置和方向有效后，立方体在左、手机截图在右。

- 两者共用一个世界坐标组，中心处于相同深度，距摆放时的头部 0.65 米。摆放之后不会跟随头部。
- 使用实际手机截图，1200×2670；竖屏图片高度 0.28 米。Android 纹理为无损 RGBA32，双线性过滤，不生成 mipmap。
- 默认暂停立方体自转，便于观察细小运动；“立方体自转”按钮可恢复原来的旋转。
- “手机截图显示”可以隐藏 / 恢复图片，不会改变立方体或相机的姿态更新。
- 图片只加载一次，不运行 MediaProjection，不逐帧上传截图，不增加姿态滤波。图片中的帧率、时间和按钮都是固定的截图内容。

先不开手势和环境模块，分别看文字、手机图片内的直线 / 边缘、立方体边缘是否同步移动。文字更显眼并不能单独证明是人眼因素：文字采样闪动和整体几何位置变化也需要区分。本版本提供对照，不预设结论。

保留原空间 Demo 的其他功能及 SDK 原始相机姿态路径。没有修改稳屏、Server、官方原生 .so 或手势兼容 .so。

源码：`Assets/ServerDiagnostics/Runtime/StaticPhoneComparison.cs`；Unity 构建菜单：`XREAL → Build Static Screenshot Comparison APK`；离线核验：`ServerAppResearch/verify_screenshot_compare.py`。
