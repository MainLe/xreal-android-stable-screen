# XREAL 稳屏 0.8.0：固定到平面

手动覆盖安装 `XREAL-StableScreen-v0.8.0.apk`。Server、6DoF Demo 无需更新；包含 0.7.3 的拇指朝向与触摸范围设置。

1. 启动眼镜画面，在“将屏幕固定到平面”中点“扫描 / 重新选择平面”。应用自动切到 6DoF。
2. 缓慢观察墙面或桌面。青色线是已识别平面边界，黄色矩形是屏幕预览。
3. 默认用视线中心瞄准。先张开所选手，再捏合一次固定；也可点手机“2 秒后固定瞄准的平面”，再抬头瞄准。
4. 等待“屏幕已固定到平面”。如果还未投屏，再允许整屏投射，即可在该位置查看手机画面。

可切到“所选手食指射线”瞄准；没有可用手部跟踪时，用视线和手机按钮即可。
选择平面本身不需要无障碍权限；手势操作手机仍需开启无障碍并单独启用本次会话操控。
扫描期间手机手势触控暂停，选择动作不会发送给手机 APP。

固定后可以调整屏幕大小，位置和朝向由空间锚点保持。跟踪丢失时隐藏手机画面并暂停触控，恢复后继续。
点“取消选择 / 解除平面固定”返回普通观看；也可切到左手持屏，两种方式互斥。
固定期间距离、视线跟随和 3DoF 切换控件暂停使用；解除固定后可再调整。

本版固定在当前运行内保持，重启应用后需重新选择。支持 SDK 已识别的水平、垂直平面；没有有效平面或锚点时不会显示固定成功。
构建和离线检查已完成，实际平面检测、原生锚点创建与佩戴效果仍待安装验证。
