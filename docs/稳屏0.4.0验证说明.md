# 稳屏 0.4.0：SDK 原生眼镜输出对照

APK：`D:\Xreal\Build\Android\XREAL-StableScreen-v0.4.0.apk`，约 125 MiB。
手动覆盖安装即可，Server 1.0.1 无需更新。

这次修复的是已复现的窗口冲突：旧稳屏自建眼镜窗口后，SDK 的眼镜窗口被
Android 17 拒绝。新版只保留 SDK 创建的眼镜窗口，并维持手机切换 APP 时
Unity 的后台渲染。姿态、固定锚点、滤波算法和目标刷新率保持原样。
尚不能把构建成功视为抖动已解决。

## 先比较静态网格

1. 退出旧稳屏和空间 Demo，再覆盖安装新版。
2. 接好眼镜，沿用正常运行的 Server，保持立体 3840×1080 模式。
3. 点“启动眼镜画面”，等待眼镜出现内容。
4. 点“静态标定网格”，保持原来的空间模式和原生固定锚点。
5. 以与旧版类似的速度缓慢转头，比较移动是否连续，再尝试稍快转头。
6. 回复网格是否可见、移动是否仍不连续。先不必授权投屏。

开发者会检查 SDK 表面创建、窗口拒绝、FrameWait 及原生呈现指标。

## 网格正常后检查手机投屏

1. 点“允许整屏投射”，在系统弹窗里手动选择共享整个屏幕。
2. 切回桌面和普通 APP，检查图像是否持续更新、空间位置是否保持。
3. 横竖屏切换后检查完整画面，再停止投屏、重新授权一次。

若黑屏或授权按钮持续不可用，复制诊断信息即可。新版会报告 SDK 输出
是否就绪，不能单凭 Unity 场景已运行或约 60 fps 判定眼镜输出成功。

离线核验：Unity 构建、Java 编译、签名、ZIP 对齐、两份 GLES 着色器、
成品 APK 显示宿主代码和原生库一致性均通过。
