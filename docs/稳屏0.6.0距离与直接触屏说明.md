# 稳屏 0.6.0：屏幕距离与直接触屏

APK：`D:\Xreal\Build\Android\XREAL-StableScreen-v0.6.0.apk`。
覆盖安装原稳屏，Server 和 6DoF Demo 无需更新。本版新增功能先做离线验证，实际效果待设备测试。

## 调整距离

“调整观看”中新增屏幕距离滑块，范围 0.25～5 米，步长 5 厘米。
保留原来的默认 2 米，另有 0.45／0.60／2.00 米预设。直接触屏建议先选 0.45 米，
以实际手臂可达位置为准。

改变距离时沿原屏幕法线移动，保留朝向和观看角大小；“屏幕大小”仍独立调整。
在 6DoF 中移动身体后，可再点“1 秒后把屏幕放到视线中央”重新放置。
距离、大小、模式或画面几何变化会结束当前触控，避免把布局变化误当作手指滑动。

## 直接滑动

1. 保持“连续刷新眼镜（兼容）”开启，启动眼镜画面并允许整屏投射。
2. 沿用 0.5.0 的无障碍服务授权，再点“启用手势操控（本次会话）”。
3. 选择操控手，选择“直接触屏 + 食指滑动”（本版默认）。空间接触推荐使用 6DoF。
4. 把食指先退回屏幕前方至少约 2.5 厘米，然后向前触入屏幕。
5. 光标变绿表示已按下；保持食指在屏幕及其后方厚度区域中移动，即可连续滑动或拖动。
   不需要捏合。保持不动可长按；把手指退回屏幕前方后松开。

“屏幕后方接触厚度”默认 8 厘米，可调 2～20 厘米。开始接触的深度区域为屏幕平面到
后方设定深度。接触后额外容许前方 2.5 厘米、后边界外 3 厘米、四周边缘外 2 厘米，
以减少指尖噪声或轻微越界导致的断触；超出屏幕的坐标会夹到画面边缘。
短暂手部漏检最多原地保持 0.1 秒，光标变黄，不外推手指移动；继续漏检则抬起。

首次开启、跟踪恢复、切换模式或调节后，指尖已经位于屏幕后方时不会自动点按，
需要先退回前方再触入。这样可以防止定位恢复时误触。

直接模式的触点落在真实手机画面内，可操作画面内导航栏。原来的“射线瞄准 + 捏合”模式
仍可切回，独立 BACK／HOME／APPS 导航按钮仅在该模式显示。

已有触控续接机制、系统触控取消后需重新触入、单次触控最多 15 秒等行为继续保留。
关闭操控、停止投屏、锁屏或失去真实头部定位会结束触控。结束已有接触不能撤销手机
此前已经收到的点击、长按或拖动。

## 稍后实测重点

- 在可伸手触及的距离，食指从前方进入时能否准确按下，退回时是否释放。
- 深度在平面后方 0～8 厘米内变化时，一次滑动能否持续，是否需要增加厚度。
- 连续拖动滑块、滚动长列表、靠近画面四边、横竖屏切换后是否正确。
- 先用系统设置或普通测试页面，确认光标与手机坐标对应后再正常使用。

离线检查涵盖一次滑动仅有一次按下/抬起、前后及边缘滞回、短暂漏检与重新准备、
指尖 UV、不同距离的观看角、旋转屏幕法线，以及原手机服务的连续触控状态机。
这些检查不能代替实机手势精度和 Android 无障碍输入验证。
