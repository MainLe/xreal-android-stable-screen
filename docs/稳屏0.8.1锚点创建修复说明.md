# XREAL 稳屏 0.8.1

针对 0.8.0“可以识别平面、无法建立锚点”的反馈修正了创建流程：

- 补齐锚点映射目录初始化，按 AR Foundation 管理器的坐标空间注册。
- 临时注册失败时保留选点并限频重试，最长等待 15 秒；已注册后不重复创建。
- 以有效原生 ID 和 Tracking 状态确认成功，避免把仍在等待通知的 pending 标志误判成失败。
- 增加服务、目录、重试次数、错误、pending、跟踪状态和锚点变更事件诊断。

APK：`XREAL-StableScreen-v0.8.1.apk`，手动覆盖安装即可，Server 和 Demo 无需更新。
操作仍为“扫描平面 → 瞄准黄色预览 → 捏合或延时确认”。

本轮不需要连接手机，已进行离线回归；原生 SDK 在本机的实际失败原因尚未通过日志确认。
待恢复设备调试后再验证创建效果。若仍失败，可复制稳屏诊断，查看 planeAnchorDiagnostics 字段。
