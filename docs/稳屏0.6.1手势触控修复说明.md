# XREAL 稳屏 0.6.1

请手动覆盖安装 `XREAL-StableScreen-v0.6.1.apk`。Server 和 6DoF Demo 无需更新。

本版修复原地按住时触控续接失败而丢失抬手的问题；射线改用手掌瞄准，保留捏合前的指示位置，
捏住后移动手掌连续拖动，张开即松手。直接食指触屏使用相同的底层触控修复。

1. 启动眼镜画面，允许整屏投射，保持“连续刷新眼镜（兼容）”开启。
2. 确认系统无障碍里的“XREAL 稳屏手势操作”开启，启用本次会话的手势操控。
3. 先选“射线瞄准 + 捏合”，点“打开手势触控测试页”。
4. 对准测试按钮：快速捏合后张开应增加“点击”；保持捏合应增加“长按”。
5. 捏住滑条再移动手掌，应连续改变滑条数值；列表应能上下滚动。
6. 也可切到直接触屏，在伸手可及的屏幕上用食指触入、滑动、退出。

测试页显示手机真正收到的 DOWN/MOVE/UP、按住时长和移动事件数，可与眼镜指示球对照。
2026-11-04 实机结果：用户已确认可以正常操控。无线日志记录到完整的按下与抬起完成，
包括短按释放及连续拖动坐标更新，安装包哈希与本版成品一致。
