# XREAL 稳屏 0.7.0

手动覆盖安装 `XREAL-StableScreen-v0.7.0.apk`；Server 和 6DoF Demo 无需更新。

- 指示点改为食指指尖沿屏幕法线的垂直投影，捏合模式和直接触屏使用相同的平面坐标。
  灰色底点大小固定；上层彩点越靠近平面越小，离开平面则变大，20 厘米以外保持最大值。
  青色为悬停，绿色为按住，黄色为直接触屏短暂漏检时保持原触点。
- 开启手部跟踪时显示约 84% 透明的细线骨骼，可在“显示透明手部骨骼”中关闭。
- 新增“左手持屏”：在眼镜画面启动后，打开“将屏幕绑定到左手（本次会话）”。
  屏幕初次放在左手掌上方约 12 厘米，面向观看者，之后按所选方式跟随左手。
  默认按用户选择，同时跟随移动和转动；也保留“跟随移动，始终面向头部”选项。

左手持屏会启用手部跟踪，可独立于手机触控使用。操作手机仍需开启无障碍服务并启用
“手势操控（本次会话）”，建议选择右手。直接触屏仍需食指先退回屏幕前方，再触入接触区。

左手短暂离开跟踪范围时保留最后画面并暂停手机触控，恢复后继续跟随。
“1 秒后重新放置左手屏幕”可重新校准朝向；这一步会结束已有触控。
绑定时自动使用近手屏幕尺寸，仍可调整“屏幕大小”；普通距离和视线跟随控件暂时禁用。
关闭绑定后恢复普通观看模式及原先设置的距离。重新启动应用或退出眼镜画面后，绑定默认关闭。

新功能已通过离线构建和数学回归；透明骨骼观感、指尖投影与左手持屏仍需实机确认。
