# 稳屏 0.4.1：静止界面持续刷新对照

APK：`D:\Xreal\Build\Android\XREAL-StableScreen-v0.4.1.apk`，约 125 MiB。
手动覆盖安装，Server 无需更新。

0.4.0 已成功创建 SDK 眼镜窗口，但实测反馈为：手机不动时约 1 fps，拖动
大小滑块时眼镜画面和转头恢复流畅。本版验证是否缺少独立的持续刷新触发，
不修改跟踪、锚点、滤波或 SDK 原生库。

2026-11-03 实机反馈：开启连续刷新后静态网格非常流畅，关闭后非常卡顿；
开启时整屏投射、静止桌面及切换其他 APP 均流畅。请保留该开关开启。
普通手机滑动在关闭时未能带动眼镜刷新，与“调整大小滑块”有区别；
不能把任意手机 UI 活动都视为眼镜刷新触发。

1. 启动眼镜画面，切到“静态标定网格”，先不开投屏。
2. 保持“连续刷新眼镜（兼容）”开启。
3. 停止触摸手机至少 5 秒，再缓慢转头，观察是否仍约 1 fps。
4. 如果已流畅，可关闭该开关，停止触摸 5 秒后重复观察，再重新开启。
   这样能在同一包、同一姿态设置中做对照。
5. 网格通过后再开启整屏投射，切到静止桌面或普通 APP，检查手机无动画时
   眼镜是否仍能随头部运动持续刷新。

兼容刷新只在 SDK 已有眼镜窗口边角绘制一个 2×2 像素的深色区域；不创建
第二个窗口、不截取或保存图像。持续绘制会增加耗电，可通过开关关闭。

如后续再次卡顿，保留现场并回复具体表现即可。诊断中的 Unity fps、SDK provider
刷新率和刷新视图绘制次数均不等于测得的眼镜光学帧率。
