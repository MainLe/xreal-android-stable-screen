# 新功能离线构建：手势操控手机与立方体惯性

这两份 APK 是新功能待实测版本。Server 沿用现有 1.0.1，无需更新。
不需要现在连接手机；稍后按原来的方式手动覆盖安装。

## 稳屏 0.5.0

文件：`D:\Xreal\Build\Android\XREAL-StableScreen-v0.5.0.apk`。
包名不变，覆盖原稳屏，保留连续刷新、3DoF/6DoF、投屏和原有设置。

启用顺序：

1. 启动 Server 和眼镜画面，保持“连续刷新眼镜（兼容）”开启。
2. 允许整屏投射，确认手机画面正常。
3. 在“手势操作手机”中打开系统无障碍设置，手动启用“XREAL 稳屏手势操作”。
   系统可能要求先在该应用信息页允许受限设置，按系统实际提示操作即可。
4. 返回稳屏，点“启用手势操控（本次会话）”，选择左手或右手，默认右手。
5. 把所选手放进眼镜可见范围，先松开手指，再瞄准并捏合。

操作：

- 画面上的青色光标由肩部参考点到拇指/食指中点的射线控制。
- 短捏合：点击。保持不动：长按。捏住并移动：连续拖动、滑动或滚动。
- 手机画面下方 `BACK / HOME / APPS`：瞄准后捏合、松开，分别为返回、主页、最近任务。
- 点手机上的“停止手势操控”可立即结束操控；退出 XR 会话后关闭，下一次需主动启用。
- 停止投屏、丢失跟踪或横竖屏转换，会结束已有接触；恢复后需要松开再重新捏合。
- 单次保持触控最多 15 秒；系统触摸中断后也需松开再捏合。手动触摸手机与注入手势可能互相取消。

无障碍服务用于把你主动做出的手势发送到手机默认显示器，不读取界面节点、不自动选择目标，
不输入文字、不录音、不上传数据。服务开启与本次会话手势操控是两个独立开关；只有开启操控、
整屏投射和眼镜真实跟踪都有效时才注入触控。手部算法首次启动可能出现一次初始化停顿。

定位、无障碍授权、点击位置是否准确、长按/拖动体验和旋转后的映射都需要实际设备验证。
第一次测试建议先使用系统设置页或空白桌面。

## 6DoF Demo 1.1.0

文件：`D:\Xreal\Build\Android\XREAL-CubeInteraction-v1.1.0.apk`。
包名仍为 `dev.xreal.server.features`，可覆盖截图对照 Demo；原来的静态截图、锚点和环境功能保留。
启动默认不开手势，到“手势”页点“启用手部跟踪”。

- 一只手靠近立方体捏合：抓住；移动手：平移；转动手腕：旋转。
- 抓住后另一只手靠近并捏合：以双手中点和方向旋转、移动；不会改变立方体大小。
- 挥动后松开：按最近手部运动赋予平移和旋转惯性，逐渐衰减并停止，没有重力。
- 张掌靠近立方体并向它推动：赋予推动速度。单纯把手放在附近不会持续加速。
- “停止立方体惯性”：立即停下。“把交互方块放回面前”：复位位置、旋转和惯性。
- 跟踪丢失、模式切换、关闭手势或进入静态基线会停止相关抓取；丢失跟踪不当作甩出动作。
- 甩出速度上限 3 m/s，旋转上限 6 rad/s；无环境碰撞模拟。使用复位按钮可找回方块。
- “捏合创建锚点”开启时立方体交互暂停，避免一次捏合同时抓物和建锚点。

## 离线验证与稍后实测

离线检查覆盖手机图像 UV 方向、与帧率无关的阻尼、无重力、四元数角速度和过期采样；
使用实际 Java 服务代码配合确定性的 Android 适配层，验证了触控续接、松手、旋转、捕获停止、
跟踪超时和系统取消后的状态。这些检查不能替代真实 Android 无障碍输入和眼镜手部识别测试。

两份 APK 均已通过签名、ZIP 对齐、GLES 着色器、成品 APK 交互代码及 SDK 原生库一致性核验。
本轮没有连接或安装到手机，不宣称新手势功能已通过设备验收。
