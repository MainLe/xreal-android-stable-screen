# 0.6.0 可调距离与厚度接触区

2026-11-04。用户要求增加距离调整，并以屏幕及其后方厚度检测直接滑动。

`StabilizedScreen.screenDistance` 默认仍为 2 米，Java 偏好值限制 0.25～5 米。
`FitSize` 随距离线性缩放，使原有角宽高和 zoom 含义保持一致；改距离时
`ShiftDistance` 只沿锚点法线移动，不改变旋转。用户重新居中仍使用当前头部姿态。
显式几何版本让距离、大小、翻转、模式、投屏尺寸或重新居中变化结束已有输入。

`FeatureHandRig.TryGetIndexTip` 直接返回所选手有效食指指尖，不要求拇指有效或捏合。
`HandPhoneControl` 将它投影到实际手机 image 的 right/up/forward 世界轴上，
按实际 lossyScale 计算平面坐标和 UV，保留原来的纹理上下校正和默认显示器映射。
屏幕 forward 为远离初次观看者的方向，正深度是屏幕后方。

`DirectScreenTouch` 是可离线检查的接触状态机：

- 输入初始/重置不准备触控，先在前方 z < -0.025m 看到手指后才允许开始。
- 按下：UV 在画面内，z 位于 [0, rearDepth]；rearDepth 默认 0.08m，可调 0.02～0.20m。
- 保持：z 位于 [-0.025, rearDepth+0.03]，XY 位于画面四周各扩 0.02m 的区域内。
  保持期间边缘 UV 夹到 [0,1]，不向其他手机坐标注入越界输入。
- 短暂关节丢失不超过 0.10s 时保持最后 UV，不外推；更长则结束，并要求重新到前方准备。
- 开关、捕获停止、头部定位失效和几何变化直接取消，不套用手指漏检容忍期。
- 一个厚度区内滑动续接原 `PhoneGestureService` 笔画，不每帧创建新点击。

默认交互模式改为直接食指触屏；保留射线捏合模式及其独立导航标签。
无障碍服务权限、单次 15 秒上限、350ms 消息看门狗、锁屏和几何保护保留。
公开诊断新增 screenDistanceMetres、handTouchMode、directTouchDepthMetres。

Unity `DirectScreenTouchChecks` 验证完整连续滑动、厚度与边界、漏检、重新准备、UV、
角大小及旋转法线位移；既有 Java 触控状态机适配层检查继续通过。
原 SDK/兼容原生库、连续刷新和姿态滤波算法保持不变；本轮只构建稳屏，不要求设备连接。
